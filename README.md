## 📖 Overview

> **Beyond Sight** is a 2D narrative puzzle adventure game developed independently in Godot 4 within a 3-week University Game Jam.

You are assigned a critical mission: uncover the error of the world and make the necessary choices to fix it. Let's see if you can discover the truth and make it right :)

---

## 🕹️ Controls

| Action | Key | Description |
| :--- | :---: | :--- |
| **Movement** | `↑` `↓` `←` `→` (Arrow Keys) | Move character in 4 directions with animated transitions |
| **Interact / Talk** | `E` | Talk to NPCs, examine clues, and enter passages |
| **Flashlight** | `W` | Toggle flashlight on/off to illuminate the dark and reveal hidden secrets |
| **Advance Dialogue** | `Space` / `Enter` / Left Click | Proceed through dialogue text and select branching choices |

---

## ✨ Key Features

### 1. 🔦 Dynamic Lighting & Hidden Realities
* Uses Godot 2D lighting combined with directional area detection.
* The flashlight is not just for vision, it is an active puzzle-solving mechanic. Shining light on specific areas reveals invisible symbols, hidden doors, and triggers reactive environmental elements.

### 2. 💬 Branching Dialogue & Narrative
* Powered by the **Dialogue Manager** addon to provide immersive, character-driven storytelling.
* Dialogue decisions influence character relationships and story progression.

### 3. 🗺️ Handcrafted Interconnected World
* Hand-drawn atmospheric maps: ...No spoilers — go see for yourself!
* Rich environmental storytelling paired with custom pixel art and ambient visual cues.

### 4. 🎭 Multiple Endings
* Retrieve the lost memory drives scattered across the world to access the central computer mainframe.
* The player's final decision determines whether the simulated world is terminated or given a chance at rebirth.
* However... not yet complete :(

## 🛠️ Technical Architecture

* **Game Engine**: [Godot Engine 4.x](https://godotengine.org/) (Forward+ Renderer, CanvasItems 2D scaling)
* **Programming Language**: GDScript
* **Addons & Dependencies**:
  * [Dialogue Manager](https://github.com/nathanhoad/godot_dialogue_manager) by Nathan Hoad — Manages branching conversation trees, conditionals, and in-dialogue state changes.
* **Target Platforms**: Web (HTML5 / Emscripten) and Desktop (Windows / macOS).
